# Sources and branding

The examples continue the five Machine example projects: [GPU batch object detection](https://github.com/MachineDotDev/gpu-batch-object-detection), [parallel hyperparameter tuning](https://github.com/MachineDotDev/parallel-hyperparameter-tuning), [supervised fine-tuning](https://github.com/MachineDotDev/llm-supervised-fine-tuning), [GRPO fine-tuning](https://github.com/MachineDotDev/grpo-fine-tune) and [language model arena](https://github.com/MachineDotDev/language-model-arena). This repository starts with fresh history and updated workloads.

The banner (`assets/machine-banner.png`, 2560×1280) is a cropped, rotated
close-up of the Machine mark (`https://machine.dev/brand/svg/mtron-mark.svg`),
designed on 18 November 2026. The mark (`assets/machine-mark.png`) came from
`https://machine.dev/brand/services/wordmark/mark-transparent-256.png` on
12 October 2026.

They retain Machine's existing black, white and green branding. The MIT license covers repository code; it doesn't grant ownership of Machine trademarks or upstream models and datasets.

Runner setup follows the [Machine quickstart](https://machine.dev/docs/quickstart/) and [Actions syntax](https://machine.dev/docs/reference/actions-syntax/). Model training follows the current [TRL SFT](https://huggingface.co/docs/trl/sft_trainer) and [GRPO](https://huggingface.co/docs/trl/grpo_trainer) APIs. Model and dataset licenses still apply to downloaded material.
